# Hash PayStream Swap integration

Home now shows Send, Receive, Swap, xStocks. Swap opens the same clean two-row list as Receive: USDC on Arc and xStocks on X Layer. The selected flow uses Hash PayLink hosted wallet sessions and directly reuses Pocket swap components and execution checks.

The server verifies the local account, loads its verified Hash PayLink connection and submits the linked identity to the fixed shared API origin. Client-supplied user IDs, wallet addresses and redirects are never trusted. The returned chain, rail, authority and checkout path must match. Account changes clear links; session loading has a deadline. Android uses the existing external browser handoff.

Required backend key: HASHPAYSTREAM_WALLET_SWAP_API_KEY, wallet:swap only. This is separate from balances, Circle transfers, Trade and connection keys. Existing hosted account configuration is also required. The shared wallet is the user's linked Hash PayLink wallet; linking does not migrate balances from the older Hash PayStream Privy wallet.

Passed: TypeScript, proxy validation and UI tests. Shared service tests cover project/account/network/authority isolation, immutable retry, paused recovery, unchanged Pocket provider guards and separate CLI scopes. Read-only live quote probes passed for Arc 5042 and X Layer 196. No financial transaction was executed. Owner authorization and key handoff remain required before live user execution.
